# Access Checklist — {{PROJECT_NAME}}

Send this to the client (or walk through it together if it's a
friend/family handoff — don't skip it just because it's informal).
Every item on here caused real delay on WePipe when it wasn't sorted
early — this exists so it doesn't happen again.

**Start the slow ones immediately, even before real work begins.**
Google Business Profile verification specifically can take days to
weeks (postcard or phone verification tied to the real business) — it's
the single biggest bottleneck we hit, and there's no way to speed it up
once started, only a way to avoid delaying the start.

## 1. Domain & Hosting

- [ ] Who owns/manages the domain registrar? (GoDaddy, Namecheap,
      Cloudflare, etc.) — need DNS access, or someone who has it and will
      act on our instructions
- [ ] Is there a current live site? If so, where's it hosted, and do we
      need access to it (for content/asset migration) or just the domain?
- [ ] Confirm who has final say on when to actually cut the domain over
      to the new site — don't do this without explicit sign-off, it's a
      real, visible change to a live business

## 2. Google Business Profile (GBP)

- [ ] Does a GBP already exist for this business? If yes: need to be
      added as a manager/owner on the existing profile.
- [ ] If no: **start creating/claiming it now**, even before the site is
      ready — verification (postcard or phone, tied to the real business)
      is the slowest part of this whole process and can't be
      parallelized with anything except waiting.

## 3. Analytics & Search Console

- [ ] Does GA4 already exist? Need to be added as a user, or need the
      property created if not.
- [ ] Same for Google Search Console.
- [ ] If neither exists yet, that's fine — just flag it, get it wired up
      once the site is live rather than blocking on it now.

## 4. Real Business Info (NAP)

- [ ] Exact business name (as they want it publicly represented)
- [ ] Real phone number
- [ ] Real address (or service-area description if no public storefront)
- [ ] Real hours, including any emergency/24-7 availability
- [ ] Existing social media accounts (used for schema `sameAs` + trust
      signals — real accounts only, never invented)

## 5. Credibility Assets (get these now, don't wait)

- [ ] Real testimonials/reviews they're comfortable sharing (never
      fabricated — if they don't have any yet, that's a real gap to note,
      not something to paper over)
- [ ] Any license/certification numbers relevant to their trade
- [ ] Real photography if available (vs. defaulting to stock — flag
      explicitly if stock is being used, don't let it look like real
      photography by accident)
- [ ] Logo / existing brand assets, if any

## 6. Decision Authority

- [ ] Who has final approval on content before it goes live?
- [ ] Who can we go to directly with fast questions, without waiting on
      a bigger meeting?
